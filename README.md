# qualitative-coding-cards

A Claude Code skill for First Cycle qualitative coding of research evidence laid out in Figma. Claude reads the participant section through the Figma MCP, does the coding, and writes one card per code back onto the canvas next to its evidence.

See [SKILL.md](./SKILL.md) for the skill, [REFERENCE.md](./REFERENCE.md) for lens definitions and Figma scripts, [EXAMPLES.md](./EXAMPLES.md) for usage.

## Lineage

- `dovetail-code`: same coding procedure, writing highlights into Dovetail.
- `qualitative-coding-cards-figma`: the original version of this workflow, run by Figma's in-app AI.

Coding method follows Saldaña, *The Coding Manual for Qualitative Researchers* (4th ed., 2021).
